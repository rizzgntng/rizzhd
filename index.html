Perintah & Script Instalasi Termux

Salin perintah di bawah ini dan tempelkan pada terminal Termux Android Anda.

termux ~ rizzhd-installer 
# 1. Update & Upgrade Paket Termux
pkg update && pkg upgrade -y

# 2. Berikan Izin Akses Penyimpanan HP
termux-setup-storage

# 3. Install Dependensi (Python, Git, FFmpeg, & Build Tools)
pkg install python git ffmpeg libjpeg-turbo libpng clang make cmake -y

# 4. Clone Repository Resmi rizzhd
git clone https://github.com/rizzgntng/rizzhd-enhancer.git
cd rizzhd-enhancer

# 5. Install Modul AI & PyTorch Requirements
pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

# 6. Jalankan Tool HD Enhancer
python main.py --input /sdcard/Download/video_buram.mp4 --scale 4x --face-restore
